# Working in this repository

- Deliver small increments tied to docs/PLAN.md, with a clear problem and runnable evidence.
- Explain the current increment in plain language; include a request/failure trace or exercise
  when it helps learning. Do not assume the owner has demonstrated understanding.
- Keep implemented behavior, intended behavior, and measured results distinct.
- Do not invent deadlines, completion dates, performance claims, authorship, or user adoption.
- Preserve credits for reused code and describe AI assistance accurately.
- Prefer standard-library solutions until a dependency solves a concrete need.
- Test meaningful network and failure behavior. Use race detection where the toolchain supports it.
- Keep this repository private unless the owner explicitly requests a visibility change.
- Do not provision paid infrastructure without explicit authorization.
- Keep credentials, model weights, and private workload data out of Git.
